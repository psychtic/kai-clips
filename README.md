# kai-clips

Robot that finds Kai Cenat clips on Twitch, makes them vertical with hooky captions, and sends them to Telegram for review. Publishing to YouTube, Instagram and Facebook comes next.

Secrets needed (GitHub, Settings, Secrets and variables, Actions):
- `TELEGRAM_BOT_TOKEN`
- `TELEGRAM_CHAT_ID`
- `ANTHROPIC_API_KEY` (optional, gives much better hook lines)
